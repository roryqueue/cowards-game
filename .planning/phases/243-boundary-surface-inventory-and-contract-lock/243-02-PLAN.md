<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source/artifact discovery -> inventory row | Static code and prior evidence are summarized into rows that downstream phases will treat as authoritative. |
| private implementation detail -> public planning artifact | Inventory must identify private data risks without copying private Strategy data, raw diagnostics, artifact bytes, tokens, paths, or runtime internals into artifacts. |
| Phase 243 contract -> Phase 244-248 behavior | Rows assign behavior-changing work to downstream phases; Phase 243 must not silently fix or relabel behavior. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-243-06 | Information Disclosure | `.planning/artifacts/v1.35-boundary-surface-inventory.md` | mitigate | Describe privacy risk categories and source file paths only; do not include Strategy source, artifact bytes, raw diagnostics, tokens, env values, DB details, host paths, package paths, or private runtime internals. |
| T-243-07 | Repudiation | decision register | mitigate | Every row must carry affected requirements, disposition, required tests/proof, and downstream phase so later behavior changes can trace to the locked contract. |
| T-243-08 | Elevation of Privilege | alias/account/provider rows | mitigate | Treat retained aliases, local Workshop identity, account source reads, provider proof, package policy, TinyGo visibility, and owner-debug as potential bypass surfaces until later phases prove otherwise. |
