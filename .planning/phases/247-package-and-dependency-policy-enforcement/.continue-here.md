<decisions_made>

- Decided to make package policy spec-owned and versioned because existing package gates were scattered and needed a single monitored source of truth.
- Decided not to enable any package ecosystem or package lane. Current production package mode stays `none` for TypeScript, Python, Rust, Zig, and hidden TinyGo.
- Decided to make Go public runtime semantics fail-loud for declared package metadata, so a malformed revision cannot be publicly labeled as clean while eligibility rejects it.
- Decided future package support must require reproducible dependency resolution, lockfiles, supply-chain policy, native-code/build-script policy, sandboxed build/install, deterministic output proof, cache invalidation, privacy redaction, rollback, and runtime-boundary proof.
</decisions_made>
