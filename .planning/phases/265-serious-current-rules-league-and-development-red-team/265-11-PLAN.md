## Source-only supervisor and publication correction

The source gate must prove an outer monotonic command-entry supervisor for every live selector. A separately supervised prestart child exclusively fsyncs a selector-attempt latch before the live child spawns; crash before the latch has no live child, while a present or uncertain latch permanently forbids re-entry. The outer process owns the live child process group; the nested Match worker inherits that group, while exact-owner cleanup may target only the admitted worker/container. Prepare, preflight and run each create an exclusive `.pending-v3` record in the child. Preflight also durably creates its attempt marker before any live host observation; run durably creates its attempted-result marker before fresh host observation. A killed child, stage/IPC loss, missing disposition or pending-only record permanently consumes the route without a second attempt.

After complete ordered IPC, clean child exit, exact pending recheck and deadline/cleanup checks, the outer parent authorizes a distinct supervised publisher with a one-shot completion instruction. The publisher exclusively fsyncs a rooted selector-specific permit, atomically publishes the canonical allocation, disposition or result, and only after canonical file and directory fsync return publishes the matching rooted commit receipt. The parent keeps a hard publisher deadline and bounded read-only reopen reserve; it does not perform an uninterruptible permit/canonical/receipt write itself. Every downstream selector and read-only verifier requires the exact canonical + permit + receipt join. Canonical bytes without a receipt are ineligible; a lost publisher IPC after receipt publication is resolved by read-only reopening, never a second write. Source tests must fault immediately before and after pending, permit, canonical and receipt publication for all three selectors, including duplicate invocation and parent/publisher crashes. No source-only test invokes a real host, Docker daemon, provider, Strategy or Match.

The outer clock must prove a positive cell and normal cleanup within 240000 ms, a separate emergency cleanup of at most 30000 ms after timeout, and the whole run including final publication within 600000 ms from command entry. Do not enter a cell without sufficient parent-clock margin. Injected hangs must show owned nested-worker termination and no stale/unrelated PID or container kill. Success requires all six ordered stage entries; a failed/denied path may retain only truthful entered stages. This technical correction does not change source-gate `empiricalAuthority:false` or grant Plan 12 authority.
