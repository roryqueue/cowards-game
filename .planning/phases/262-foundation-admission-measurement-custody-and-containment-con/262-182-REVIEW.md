The bounded fix is to parse and compare the exact repository and SHA-256 digest while continuing to execute only the configured digest-pinned reference. Floating tags and any different repository or digest must still fail.

### CR-02: Ambiguous `docker create` outcomes lack cleanup ownership

`scripts/lib/v1-38-lean-container-match-session.ts` validates create status, stderr, and returned ID before it defines removal. A status-zero response with stderr, malformed ID, or timeout after creation can throw without removing the container, and no deterministic name exists to recover ownership.

The bounded fix is a collision-safe deterministic container name plus cleanup-by-name or validated-ID on every ambiguous create outcome, with fail-closed absence/removal confirmation and fault-injection tests.
