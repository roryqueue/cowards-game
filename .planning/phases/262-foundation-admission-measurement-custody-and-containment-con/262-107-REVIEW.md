## Findings

### F-262-107-01 — Generic dependency injection bypasses the closed custody gate

**Severity:** critical  
**Location:** `scripts/run-v1-38-bounded-retry-envelope-v3-live-v8.ts:416-440,638-695,681-714`

`V138LiveV8Dependencies` exposes replacements for the pair checker, Plan-93 authenticator, review authenticator, supplement authenticator, execution-closure authenticator, protected-history check, destination-absence check, and producer. Both exported production functions accept `Partial<V138LiveV8Dependencies>`, merge those replacements over the real dependencies, and then invoke `runProducer` with `validateInputs:false`. An importing caller can therefore fabricate every asserted structure, inject the real `runV138V3ProductionLive` as `runProducer`, and reach live effects without any disk-backed review, supplement, history, destination, or execution-closure authentication.

The tests demonstrate that this is a public runtime seam rather than a test-only implementation detail: they call the exported live function with synthetic replacements for every gate. This directly violates Plan 107's requirement that tests may inject fake effects but the adapter must not export a generic validation bypass.

**Required fix:** remove dependency injection from all exported production/live entry points. The exported live function and CLI must close over the real authenticators and producer. Exercise behavior through owner-only disposable repositories, or keep any synthetic core unreachable from production imports and incapable of receiving the real producer. Add a regression proving no exported API can substitute a gate while retaining the production effect function.

### F-262-107-02 — Protected-history authentication is incomplete and ignores dirty bytes

**Severity:** critical  
**Location:** `scripts/run-v1-38-bounded-retry-envelope-v3-live-v8.ts:354-387`

Plan 107 requires the adapter to authenticate protected Plans 90/91/96/97/98/99/100/101/102/103/104/105 before effects. `PROTECTED_SUCCESSOR_PATHS` directly covers only selected Plan-101, Plan-103, and Plan-105 paths plus portions of the producer/pair implementation. It omits the named Plan-90/91/96/97/98/99/100 history and does not provide a complete explicit raw-byte manifest for Plan-102/104.

Furthermore, `assertProtectedHistoryUnchangedFromDisk` runs only `git log PAIR_COMMIT..HEAD`. That detects later committed changes for listed paths but does not compare their current regular-file bytes/modes with the committed blobs, so uncommitted replacement or modification of a listed protected artifact is accepted. The static `protectedHistoryRoot` check in the pair does not authenticate those current bytes.

**Required fix:** bind the complete Plan-90/91/96/97/98/99/100/101/102/103/104/105 protected-path inventory, expected commits, raw blobs, modes, and semantic roots. Require current regular no-follow bytes to equal the expected committed blobs and prove no later rewrite for every entry. Add one mutation test per protected branch plus dirty-working-tree tests.

### F-262-107-03 — Producer rejection skips the required post-effect closure check

**Severity:** high  
**Location:** `scripts/run-v1-38-bounded-retry-envelope-v3-live-v8.ts:686-703`

The post-run protected-history and execution-closure checks occur only after `await deps.runProducer(...)` resolves. If the producer throws after acquiring its lease or after any journal/private/terminal effect, the function exits immediately and never authenticates the post-effect executable closure. The existing test covers closure drift after a resolved synthetic producer but has no rejection-path assertion.

This leaves the before/after custody guarantee incomplete on exactly the exceptional paths where fail-closed evidence is most important.

**Required fix:** perform the post-effect protected-history and execution-closure authentication in a `finally`-equivalent path after every producer outcome, while preserving the original producer failure and surfacing any concurrent custody failure. Add tests for producer rejection with unchanged custody and producer rejection combined with closure/history drift.
