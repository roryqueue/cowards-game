**Issue:** `inspectOwner` returns `absent` for every transport result with `status === 1` before checking the error stream or proving Docker reported the exact no-such-object condition. Prefer a bounded exact-name inventory query whose clean empty output proves absence; otherwise validate a stable machine-readable absence result. Treat all other status-1 results as `unknown`, and add fault tests for status 1 with non-absence stderr both before create and after removal.
