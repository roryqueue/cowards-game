# Phase 268: Equal-Compute Retraining and Branch Freezes - Context

**Gathered:** 2026-07-27
**Status:** Discussion complete; planning and execution denied pending Phase 262 ADMIT-03

<domain>
## Phase Boundary

This phase begins only after Phase 267 has proved the three private, position-only formation arms and their production unreachability. It separately retrains the current-edge, inward-rank, and bracket branches from the same profile-agnostic cold root under equal structural opportunity, equal model/human pressure, isolated learning, common analysis, and complete evidence, then freezes all three branches before any sealed-holdout access. It does not open the holdout, decide whether the bracket passes, certify a production Strategy, alter a rule, or expose lab evidence through product paths.

</domain>

<decisions>
## Implementation Decisions

### Carry-forward trust charter
- **D-01:** Every allocation, task, attempt, candidate, Match, ledger shard, matrix, analysis result, and branch freeze is immutable and content-addressed. There is no mutable `latest` evidence and mutation creates a new, non-comparable branch.
- **D-02:** Missing, stale, incomplete, mismatched, contaminated, or unreproducible evidence fails closed. A process-valid empirical failure remains an honest outcome, but a process or integrity failure blocks branch freeze and holdout access.
- **D-03:** Every Match advances through the exact selected canonical `MATCH_KERNEL`; emitted Strategy source remains hostile and executes only through the supervised runtime boundary. No copied rules, alternate scheduler, web/API/Go execution, or lab-specific transition logic is permitted.
- **D-04:** All three arms, including current-edge, remain private lab evidence. Their sources, traces, telemetry, prompts, and learned artifacts cannot enter canonical registration, persistence, counted or exhibition scheduling, Chronicle, standings, replay, or public/default output.
- **D-05:** Every attempted allocation, rejection, invalid output, retry, player violation, system failure, and unused allocation remains charged and visible. No failure may disappear through replacement, padding, or selective rerun.
- **D-06:** Cycle cap, MOVE/reversal, Backstab geometry or timing, activation counts, arenas, runtime, and every other rule remain fixed. Only exact eligible pre-formation current-league source hashes may later approach canonical certification; no Phase-268 branch candidate is eligible.

### Equal structural opportunity
- **D-07:** Equality is an exact vector of predeclared opportunities, not one fungible compute score, elapsed time, cost estimate, or normalized scalar. Doctrine/core eligibility, candidate attempts, accepted response slots, oracle rounds, structured-search evaluations, teacher nodes, distillation work, Match cells, model work, human work, and replay review are independently reconciled.
- **D-08:** The primary comparison starts all three branches from one profile-agnostic cold common root and the same matched, domain-separated root-seed blocks. Fixed-policy transfer is screening evidence only.
- **D-09:** A current-trained warm-start experiment is permitted only as a separately labeled sensitivity block that gives all three arms the same frozen source snapshot, allocations, and rules. Warm-start evidence cannot replace or repair the cold-root primary comparison.
- **D-10:** Each arm receives identical side, initial-initiative, semantically distinct design-arena, split, runtime/source/memory/objective/output, hardware-class, cache, retry, trace-retention, and replay-review policies.
- **D-11:** If an arm cannot fill an accepted-response slot, it follows the frozen failure disposition. The shortfall and unused opportunity are recorded; there is no free search, substitute candidate, silent padding, budget transfer, or opportunistic extension.

### Equal model and human pressure
- **D-12:** All arms use the same frozen provider/model identities and settings, provider-neutral prompt/request templates, token and attempt limits, human submission and reviewer-hour budgets, disclosed artifact categories/counts/timing, validation, replay-review effort, and response handling. Only allowlisted profile identity, declared geometry, and branch-local evidence substitutions may differ.
- **D-13:** Reuse the same model and human pools across arms, counterbalance the frozen profile order and reviewer reuse, and blind profile labels during telemetry review wherever the task can remain meaningful while blinded.
- **D-14:** A required provider/model identity becoming unavailable or drifting does not authorize an arm-local substitute. Invalidate the affected comparison and restart all three arms under one new common root with an equally applied, newly frozen identity block.
- **D-15:** Cross-channel disclosure follows the frozen contract. No model, human, reviewer, or automated oracle receives another arm's post-freeze learned candidate, score, prompt response, counter, replay, telemetry result, or holdout information.

### Branch isolation and deterministic execution
- **D-16:** Current-edge, inward-rank, and bracket use disjoint namespaces, stores, caches, lineage graphs, candidates, scores, labels, prompts, traces, replay-review material, and learned artifacts. Shared inputs stop at the frozen profile-agnostic common root and explicitly allowlisted non-learned code/contracts.
- **D-17:** Preassigned task identities, domain-separated streams, atomic shards, and canonical reduction order make worker count, shard size, completion order, restart, resume, and profile execution order non-semantic. Reordering the three branches must reproduce identical branch roots.
- **D-18:** All arms use the same analysis executable and the classifiers, denominators, thresholds, replication treatment, and non-compensating logic frozen in Phase 262. Branch-specific analysis changes create incomparable evidence and invalidate the run.

### Consumption audit and branch freezes
- **D-19:** A pre-run allocation audit proves vector equality. A post-run consumption audit joins every planned opportunity to actual immutable evidence, charges failures and retries under the frozen rule, and records genuine unused budget without manufacturing work.
- **D-20:** Any unexplained overage, free retry, missing receipt, unrecorded work, asymmetric disclosure/review, cross-branch learned dependency, or materially advantageous underuse invalidates the comparison. Materiality rules must be fixed by the named equal-work spike before production-scale runs and cannot be changed after results.
- **D-21:** Each arm must close complete condition-balanced matrices, response graphs, pure-finalist dispositions, runtime evidence, equal red-team outputs, and all contracted formation telemetry under the same code. Missing or system-failed required cells block that arm's freeze rather than being imputed.
- **D-22:** Each branch freezes its exact population, finalist set or no-finalist disposition, thresholds, red-team evidence, compute ledger, manifests, analysis identity, and result roots before any common sealed-holdout access. No branch can freeze provisionally while another continues learning.

### the agent's Discretion
Only after the required equal-work, common-root, cache-isolation, classifier, and branch-reordering spikes pass, the agent may choose the internal module decomposition, strict schema names, deterministic shard size, worker-pool size, cache directory layout, canonical integer/rational encoding, and CLI command names. Those choices may not scalarize the opportunity vector, weaken an equality or failure gate, alter a frozen classifier, add a new profile, or make execution order semantic. Unresolved ambiguity defaults to fail-closed evidence rather than inferred equality.

</decisions>

<specifics>
## Specific Ideas

- Treat equal opportunity as a visibly reconciled multidimensional vector; never hide inequality by converting model tokens, human hours, search nodes, and Matches into one score.
- Preserve real underuse as evidence. Synthetic padding would obscure whether a profile was harder to search and is not neutral.
- Cold-root evidence is primary; equal warm-start sensitivity is informative but cannot rescue the primary comparison.
- A provider identity failure restarts the comparison symmetrically instead of giving one arm a replacement advantage.

</specifics>
