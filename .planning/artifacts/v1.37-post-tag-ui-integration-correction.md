## Supplemental audit findings

### F-01 — public Strategy runtime semantics were stripped

`PublicStrategyCardDto` required `runtimeSemantics`, but its Zod schema omitted
the field. Zod therefore stripped valid Go/service data and the public Strategy
page failed when it tried to render the missing projection.

Correction:

- Add the shared runtime-semantics projection to
  `PublicStrategyCardDtoSchema`.
- Keep service and Go contract examples/tests exact.
- Regenerate the OpenAPI document and Go public-read fixtures.

### F-02 — MatchSet counted rendering failed open

The MatchSet page and result view model treated every state except the literal
`non_counted` state as counted. Missing, pending, failed, and
`non_competitive` projections could therefore be presented as counted. Local
proof fixtures also used counted-eligible copy even though proof-local
containment does not authorize counted play.

Correction:

- Render an entrant as counted only when the authoritative projection is
  exactly `counted`.
- Treat missing and every other state as non-counted.
- Make local and Go parity fixtures explicitly non-counted with
  `NON_COUNTED_RUNTIME`.
- Add regression coverage for `non_competitive`, pending, and absent
  projections.

### F-03 — the D-11 release matrix assumed the repository root

The v1.37 persistence rollback test resolved owner files from `process.cwd()`.
The normal root `turbo test` command runs that test from
`packages/persistence`, duplicating the package path. Turbo also did not pass
the explicitly supplied release database variables into package test tasks.

Correction:

- Resolve the repository root from `import.meta.url`.
- Run nested owner suites from that stable root.
- Pass the three documented test-database variables through the Turbo test
  task without embedding values.

## Semantic and safety ruling

This correction changes public admission/rendering and test orchestration only.
It does not change a valid Match state, Action legality, event order, outcome,
terminal timing, Strategy observation, canonical event, or v1.4 historical
interpretation. No compatibility approval is required.

All four proof-local language lanes remain non-counted. System failure remains
no-commit and cannot become a player penalty. Public/default output continues
to exclude Strategy source, artifact bytes, memories, objectives, diagnostics,
host data, credentials, and security internals.
