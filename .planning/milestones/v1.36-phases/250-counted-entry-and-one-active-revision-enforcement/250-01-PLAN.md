| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-250-01-01 | E | owner mismatch category | mitigate | Define `owner_mismatch` as a stable public category; Plan 02 maps account ownership failures to it. |
| T-250-01-02 | T | stale/mismatched proof categories | mitigate | Define separate `provider_proof_missing`, `provider_proof_mismatched`, and `provider_proof_stale` categories so stale artifacts cannot be hidden as generic errors. |
| T-250-01-03 | E | unsupported/TinyGo provider bypass | mitigate | Define the supported counted lane list as TypeScript/Python/Rust/Zig only and map TinyGo to `hidden_unsupported_provider`; JavaScript is not a Phase 250 counted trial lane. |
| T-250-01-04 | E | package/capability bypass | mitigate | Define `package_policy_violation` and `capability_policy_violation` categories required by D-04. |
| T-250-01-05 | T | duplicate/replacement entry | mitigate | Define `already_entered_season` and `replacement_blocked` categories consumed by Plan 02 preflight/race fallback. |
