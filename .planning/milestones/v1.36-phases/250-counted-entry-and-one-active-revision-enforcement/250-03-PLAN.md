| persistence error -> HTTP response | Private validation/database failure details are projected publicly. |
| public discovery -> React page | Public-safe eligibility projection is rendered by UI without owning truth. |
| Go readiness -> web discovery | Provider-level readiness labels cross service/language boundary. |
| exhibition route -> MatchSet creation | Permissive self-play/multi-revision workflows must not become counted trial entries. |
