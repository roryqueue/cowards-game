<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| signed-in user -> persistence | User-supplied Season/revision IDs cross into DB-backed eligibility checks. |
| stored provider/runtime evidence -> counted entry decision | Stored v1.35 proof and runtime metadata are reduced to public categories. |
| persistence -> API/web | Low-level validation and database failures are converted to public-safe errors. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-250-02-01 | E | owner mismatch | mitigate | Query Strategy Revision by both revision ID and current owner user ID; map misses to `owner_mismatch`. |
| T-250-02-02 | T | stale/mismatched provider proof | mitigate | Reuse v1.35 HMAC/source/artifact proof helpers and classify missing, mismatched, and stale hash/byte drift separately. |
| T-250-02-03 | E | unsupported/TinyGo provider bypass | mitigate | Enforce Plan 250-01 counted lane list in persistence; reject JavaScript/TinyGo/unknown lanes before insert. |
| T-250-02-04 | E | package/capability bypass | mitigate | Require package mode `none` and no required capabilities before mutation. |
| T-250-02-05 | T | duplicate/replacement entry | mitigate | Preflight any same-owner Season row, preserve full unique `(season_id, owner_user_id)`, and map `23505` as a race fallback. |
| T-250-02-06 | I | public error leakage | mitigate | Category-bearing `LadderInputError` exposes only spec public copy; tests scan for DB/provider/private markers. |
| T-250-02-07 | E | accidental Strategy execution in web/API/Go | mitigate | Entry consumes stored evidence only and grep gates forbid runtime execution/process APIs in `ladder.ts`. |
</threat_model>
